# Ingestion, API and UI design
Issues #7, #8. Proposed.

## Pipeline
Stream authenticated upload into quarantine, validate declared size and detected magic bytes, generate opaque asset ID, calculate SHA-256, write job intent. Scan using ClamAV fail-closed; unsupported or infected assets rejected, unavailable scanner leaves quarantined for retry. Extract EXIF/IPTC/XMP using ExifTool after scan; Sharp creates JPEG/WebP thumbnail (320px longest edge) and preview (1600px), no upscaling. Initial formats JPEG/PNG/WebP; propose 100 MiB limit and 50 megapixels decoded limit. Reject malformed and unsupported formats; preserve original. Worker parser subprocess non-root, isolated temporary directory, network denied, timeout 60s, memory limit 512MiB (validate), never interpret filenames as shell commands. Queue retry transient failures 3 times with exponential backoff; permanent failures do not retry. Deterministic job key asset ID + pipeline version + stage. Persist processing status and structured error category; retry authorized editor/admin only. Dead-letter/failed queue visible to operators; outbox re-dispatch and reconciliation recover restarts. No raw metadata secrets in logs. PoC: valid, corrupt, oversize, scanner unavailable and EICAR test files; verify no premature download, checksum and deterministic output, throughput against #12. No execution yet.

## REST conventions
/api/v1, JSON UTF-8, OpenAPI generated and checked against implementation. RFC 9457 problem details without internal paths; 401 unauthenticated, 403 denied or 404 where existence sensitive. Cursor pagination default 50 max 200, allowlisted filter/sort. Idempotency-Key for uploads/commands with scoped key + request fingerprint; mismatched replay 409. ETag/If-Match for metadata changes, stale update 412. Endpoints: /catalogs, /catalogs/{id}/categories, /assets (upload/list), /assets/{id}, /assets/{id}/metadata, /assets/{id}/content, /assets/{id}/renditions/{kind}, /assets/{id}/retry, /audit-events. Stream upload/download, HTTP Range for active authorized files; no public links. Resumable multipart deferred unless #13 requires >100MiB. Enforce same authorization on every route and range request. Cache private/no-store for sensitive content; revoke access on subsequent requests.

## UI
React/Vite SPA, TanStack Query server state, TanStack Table for lists, virtualized grid, detail/preview pane, upload progress, job status and retry, category tree and metadata form. Bulk selection scoped to current query; bulk editing deferred unless #13 selects it. Keyboard navigable grid/tree, labels, focus management, text alternatives, accessible error states; target WCAG 2.2 AA on critical flows. English UI first, translation keys prepared for German. Same-origin session cookie; no bearer token in localStorage; login/logout via API, handle 401/403 without data leak. Test with Playwright, axe-core plus manual keyboard review. Contract checks validate status codes, schema, pagination, ETag and access failures.
